# 724 现有功能

- **飞书登录**：支持飞书授权登录、登录状态校验和退出。
- **日志上传**：支持多文件上传及 LOG、TXT、OUT、CSV、ZIP、GZ、TGZ、TAR.GZ；支持加密 ZIP、异步解压解析、同名文件自动追加时间。
- **规则解析**：按启用规则搜索关键字，不区分大小写，支持 `|` 配置多个关键字；命中后保存前 50 行、命中行和后 50 行。
- **关联分析**：在关键字上下文中识别 SD 卡、I/O、文件系统、写盘、看门狗和崩溃等可能原因。
- **任务管理**：展示排队中、解析中、已完成和失败任务，实时显示文件及字节进度，支持查看详情和删除。
- **解析结果**：支持结果筛选、异常时间线、上下文查看、可能原因展示及结果导出。
- **日志记录**：记录上传文件、项目、版本、大小和时间；可定位到任务列表中的对应任务。
- **规则配置**：支持规则新增、编辑、删除、启停、分类、级别和优先级管理。
- **测试场景**：支持场景、检查项、关键字、严重程度及判定方式配置。
- **仪表板**：展示日志行数、错误数、任务数、趋势、异常关键字和最近任务。
- **可靠性处理**：支持实时任务心跳、超时任务识别、批量结果写库和数据库连接池管理。
