# LogMaster 采集端前端设计需求文档

> 文档状态：前端设计输入稿  
> 版本：V0.1  
> 更新日期：2026-07-27  
> 适用范围：Windows Wails 桌面采集端  
> 目标用户：测试人员、挂测人员、现场运维人员

## 1. 文档目的

本文档用于指导 LogMaster 采集端的产品结构、交互设计和前后端接口调整。本文档描述的是目标体验，不代表当前代码已经全部实现。

采集端核心闭环为：

```text
发现真实串口
  -> 配置端口对应的项目、版本和测试任务
  -> 打开串口并实时显示日志
  -> 按配置保存本地日志
  -> 可选开启云端上传
  -> 在上传队列查看进度和查询码
  -> 通过历史文件和关键字命中记录追溯问题
```

## 2. 已确认的产品原则

1. 一个串口对应一个独立采集通道，各通道配置、采集、存储、关键字统计和上传互不干扰。
2. 左侧通道开关控制串口打开和关闭，不再使用语义重复的“开始采集”按钮。
3. 首次打开串口失败时不循环重连，必须明确提示无法访问的原因。
4. 串口已经正常采集后发生物理拔出，可进入“等待设备”状态；重新插入后的恢复策略仍需最终确认。
5. 本地日志保存和云端上传是两项独立能力。
6. “另存日志”只在本地生成副本，不修改内部采集文件，不影响上传队列。
7. 只有已保存通道配置并开启“上传云端”的串口才进入上传队列。
8. 未开启云端上传的串口仍可正常实时显示和保存本地日志。
9. 清屏只清除当前打印窗口，不删除本地文件，也不影响上传。
10. 搜索高亮只用于用户主动搜索的文本，不在日志中固定高亮 `INFO` 等等级文本。
11. 所有日志时间和程序底部时钟统一使用格式 `[yyyy-MM-dd HH:mm:ss.SSS]`。
12. 配置文件导入必须先预览新增、修改和删除项，经用户确认后才能应用，不允许直接覆盖。
13. 需要显示每个串口的最后日志时间，并支持“长时间无日志”告警。
14. 查询码必须能被云端识别，不能由前端随意生成。

## 3. 信息架构

建议使用五个顶级页面：

| 页面 | 主要职责 |
| --- | --- |
| 采集工作台 | 串口开关、实时日志、日志配置、搜索和关键字仪表盘 |
| 历史文件 | 查询、预览、另存、导出和定位本地日志文件 |
| 上传队列 | 查看已开启云端上传通道的上传状态、进度和查询码 |
| 配置管理 | 导入项目/任务/关键字配置，预览差异并应用 |
| 设置 | 默认保存位置、存储策略、程序信息、更新日期和交流群信息 |

## 4. 采集工作台布局

建议采用稳定的三栏结构：

```text
+----------------+--------------------------------------+--------------------+
| 串口通道       | 实时日志打印窗口                   | 日志配置/仪表盘    |
|                |                                      |                    |
| COM24   [开关] | [清屏][换行][另存][历史][导出]      | 项目               |
| 采集中         | [打开文件夹]                        | 版本               |
| 最后日志时间   |                                      | 测试任务           |
| 待上传 2       | [搜索文本________][搜索][上][下]    | 关键字匹配开关     |
|                | [2/36][继续滚动]                    |                    |
| COM25   [开关] |                                      | 关键字命中仪表盘   |
| 无法访问       | [2026-07-27 15:30:12.123] log...    | timeout       12   |
|                | [2026-07-27 15:30:12.130] log...    | disconnect     3   |
+----------------+--------------------------------------+--------------------+
| 当前通道状态            [2026-07-27 15:30:12.456]   本地服务/磁盘/上传 |
+----------------------------------------------------------------------------+
```

窗口最小尺寸需要保证：

- 左侧串口列表可完整显示开关和状态。
- 中间日志区仍是最大可用区域。
- 右侧配置字段不被截断。
- 所有按钮使用固定尺寸，动态状态不得造成布局跳动。

## 5. 左侧串口列表

### 5.1 通道内容

每个通道至少展示：

- 串口号，例如 `COM24`。
- 用户设置的通道名称。
- 串口开关。
- 当前状态。
- 项目、版本、测试任务的简写。
- 最后日志时间。
- 当前接收行数。
- 当前通道本地存储占用。
- 待上传文件数或上传异常标记。
- 未保存配置标记。
- 云端上传开启标记。

### 5.2 串口状态

| 状态 | 含义 | 主要操作 |
| --- | --- | --- |
| 关闭 | 串口未打开 | 开启 |
| 打开中 | 正在申请串口 | 等待，不可重复点击 |
| 采集中 | 串口已打开并接收日志 | 关闭 |
| 等待设备 | 已开启的物理设备被拔出 | 关闭或等待重新插入 |
| 无日志 | 串口已连接，但超过阈值未收到日志 | 查看告警或关闭 |
| 无法访问 | 串口被占用、权限不足或参数无效 | 查看详情、重新尝试 |
| 磁盘不足 | 本地存储达到保护阈值 | 打开存储设置 |
| 错误 | 其他不可恢复错误 | 查看详情、重新尝试 |

### 5.3 打开失败规则

首次打开串口出现以下错误时不得自动循环重连：

- 串口被其他程序占用。
- 当前账号没有访问权限。
- 串口参数不被驱动支持。
- 串口在扫描后已经消失。
- 驱动返回其他不可恢复错误。

交互要求：

1. 开关恢复为关闭状态。
2. 通道进入“无法访问”。
3. 显示简短原因，例如“COM24 被其他程序占用”。
4. 支持打开错误详情并复制错误信息。
5. 用户再次主动开启时才重新尝试。

### 5.4 长时间无日志告警

- 串口保持打开，但超过设置阈值没有收到新日志时进入“无日志”告警。
- 告警不能自动关闭串口。
- 收到新日志后自动解除告警。
- 默认阈值建议为 5 分钟，并允许在全局设置或通道配置中覆盖。
- 通道列表和右侧状态区都应显示最后日志时间。
- 从未收到过日志时显示“尚未收到日志”，不能显示虚假时间。

## 6. 通道日志配置

### 6.1 配置层级

日志配置从大到小依次为：

```text
项目
  -> 版本号
    -> 测试任务
      -> 关键字匹配方案
        -> 关键字规则
```

字段定义：

| 字段 | 输入方式 | 说明 |
| --- | --- | --- |
| 项目 | 下拉选择 | 来自导入的配置文件 |
| 版本号 | 可输入下拉框 | 可以选择预设版本，也可以手写 |
| 测试任务 | 下拉选择 | 包含专项测试和普通挂测 |
| 关键字方案 | 选择或弹窗 | 根据项目和测试任务加载可用方案 |
| 关键字匹配 | 开关 | 用户主动开启后才开始实时匹配 |
| 自动保存日志 | 开关 | 已保存配置后默认开启 |
| 上传云端 | 开关 | 开启并保存后，后续日志进入上传链路 |

### 6.2 串口参数

- 波特率使用可输入组合框。
- 预设值：`9600`、`19200`、`115200`、`921600`、`1500000`。
- 用户可以手动输入其他合法波特率。
- 数据位：5、6、7、8。
- 停止位：1、2。
- 校验位：无、奇、偶、Mark、Space。
- DTR 和 RTS 使用独立开关。
- 当前流控只允许“无”；RTS/CTS 和 XON/XOFF 在驱动完整支持前不得开放。

修改正在使用的波特率、数据位、停止位或校验位时，保存前必须提示“保存后将重新打开串口”。

### 6.3 配置保存状态

通道配置需要明确区分：

- 未配置。
- 已保存。
- 有未保存修改。
- 配置校验失败。

目标规则：

1. 新检测到的串口可以打开并实时显示日志。
2. 未完成日志配置时，不允许开启正式本地保存和云端上传。
3. 配置保存后，“自动保存日志”默认开启。
4. “上传云端”需要用户主动开启并再次保存。
5. 修改但未保存时，采集继续使用最后一次已保存配置。
6. 切换通道、关闭程序或导入新配置时，如存在未保存修改，必须提示用户。

> 注：用户提出过“未设置配置时只实时显示”和“默认保存”两种表述。本文暂按“首次配置保存后默认保存”处理，仍需最终确认。

## 7. 实时日志打印窗口

### 7.1 日志格式

每行显示格式：

```text
[yyyy-MM-dd HH:mm:ss.SSS] 日志正文
```

示例：

```text
[2026-07-27 15:30:12.123] device boot completed
```

要求：

- 时间使用运行电脑的本地时区。
- 固定显示毫秒。
- 不显示固定 `INFO` 标签。
- 不对 `INFO`、`WARN`、`DEBUG` 等普通文本做默认高亮。
- 关键字命中标识和搜索高亮必须使用不同视觉样式。

### 7.2 自动滚动和换行

- 自动滚动默认开启。
- 用户滚动离开底部时，可提示“有新日志”，但不强制拉回底部。
- 点击搜索结果的上一个/下一个后，自动滚动暂停。
- 点击“继续滚动”后跳到最新日志并恢复跟随。
- 自动换行使用独立开关，并记住用户偏好。
- 关闭自动换行时允许横向滚动。

### 7.3 搜索

搜索区域包含：

- 文本输入框。
- 搜索按钮。
- 上一个匹配按钮。
- 下一个匹配按钮。
- 当前匹配位置，例如 `2 / 36`。
- 继续滚动按钮。

搜索规则：

1. 只有点击“搜索”或在输入框按 Enter 后执行。
2. 搜索当前通道、当前打印窗口中的日志。
3. 命中文本在打印窗口中高亮。
4. 右侧显示本次搜索的命中总数。
5. 上下按钮循环定位匹配项。
6. 当前匹配项需要使用比其他命中项更明显的样式。
7. 搜索后暂停自动滚动。
8. 清空搜索条件后移除搜索高亮。
9. 不保留原有日志等级下拉筛选框。

### 7.4 清屏

- 清屏只清除当前通道的打印窗口缓冲。
- 不删除本地日志文件。
- 不清除上传队列。
- 不清除关键字累计统计，除非用户在仪表盘中单独执行“重置统计”。
- 清屏后“导出打印窗口”只包含清屏后重新显示的日志。

### 7.5 复制整行

- 单击日志行后可复制整行。
- 右键菜单提供“复制整行”。
- 复制内容必须包含时间戳和完整正文。
- 搜索高亮标记不得进入复制文本。

### 7.6 另存日志

“另存日志”只产生本地文件，不影响上传。

交互流程：

1. 通道配置保存后按钮可用。
2. 点击后打开本地保存弹窗。
3. 默认文件名为：

   ```text
   端口号-项目-版本-测试任务-时间戳.log
   ```

4. 用户可以修改文件名和目标目录。
5. 可选择保存范围：
   - 当前打印窗口。
   - 当前通道本次采集的全部本地日志。
6. 另存文件不进入 SQLite 上传队列。
7. 另存文件不修改内部日志文件及其 SHA-256。

### 7.7 导出打印窗口日志

- 只导出当前通道打印窗口中当前存在的日志。
- 清屏前已经移除的内容不导出。
- 搜索条件不改变导出范围；导出的是当前窗口全部日志，而不是只导出命中项。
- 如需“只导出搜索结果”，应作为后续独立功能，不与本按钮混淆。

### 7.8 打开日志文件夹

- 日志配置区域展示当前默认保存位置。
- 保存位置旁提供文件夹图标按钮。
- 点击后打开当前通道日志所在文件夹。
- 如果目录不存在或无权限，显示错误提示，不静默失败。

## 8. 关键字匹配与右侧仪表盘

### 8.1 开启流程

1. 用户选择项目。
2. 用户选择或输入版本号。
3. 用户选择测试任务。
4. 系统加载该任务可用的关键字方案。
5. 用户通过弹窗或列表选择要启用的关键字。
6. 用户开启“关键字匹配”并保存配置。
7. 从开启时刻开始实时匹配。

### 8.2 仪表盘内容

每个已选择关键字展示：

- 显示名称。
- 匹配表达式的简要说明。
- 当前触发次数。
- 最近一次触发时间。
- 是否启用。

点击触发次数后展开命中记录：

| 字段 | 说明 |
| --- | --- |
| 序号 | 本关键字的第几次命中 |
| 匹配时间 | `[yyyy-MM-dd HH:mm:ss.SSS]` |
| 日志行号 | 当前采集会话中的逻辑行号 |
| 日志摘要 | 命中行的正文摘要 |

点击命中记录后：

- 如果该行仍在当前打印窗口中，定位并突出显示。
- 如果该行已离开窗口，提示用户转到历史文件查看。
- 不允许伪造定位结果。

### 8.3 匹配规则建议

配置文件应支持：

- 普通文本包含。
- 是否区分大小写。
- 正则表达式。
- 一行是否允许同一规则重复计数。
- 可选的前后文行数。
- 稳定的规则 ID。

关键字统计与用户搜索统计是两套数据：

- 关键字统计来源于已保存的测试任务规则，可持久化。
- 搜索统计来源于用户临时输入，只统计当前打印窗口。

## 9. 历史文件

### 9.1 查询条件

- 串口。
- 项目。
- 版本号。
- 测试任务。
- 日期范围。
- 文件名。
- 上传状态。
- 查询码。

### 9.2 文件信息

- 文件名。
- 所属串口。
- 项目、版本、测试任务。
- 开始时间、结束时间。
- 文件大小、日志行数。
- 本地路径。
- SHA-256。
- 上传状态。
- 查询码。

### 9.3 文件操作

- 预览。
- 打开所在文件夹。
- 另存为本地副本。
- 复制文件名、路径或 SHA-256。
- 选择历史文件手动上传。

禁止规则：

- `pending`、`uploading`、`uncertain` 文件不得删除。
- 未确认上传成功的文件不得被自动清理。
- 删除已上传文件前必须明确提示影响范围。

## 10. 云端上传

### 10.1 通道上传开关

- 每个串口独立设置“上传云端”。
- 开关变更只有在保存通道配置后生效。
- 开启后，后续封口的日志文件进入上传队列。
- 关闭后，新产生的文件只保存本地，不进入上传队列。
- 关闭开关不能删除已在队列中的文件。
- 关闭后重新开启，是否上传关闭期间产生的文件，默认答案为“不自动上传”。
- 关闭期间的历史文件如需上传，由用户在历史文件页面主动选择。

### 10.2 上传队列显示范围

上传队列默认只展示：

- 当前已开启云端上传的串口。
- 这些串口尚未完成处置的上传记录。

页面提供：

- “全部上传通道”。
- 按串口筛选。
- 按状态筛选。
- 按查询码搜索。
- 查看已完成历史记录的入口。

如果串口关闭了云端上传，但仍有历史待上传或异常批次，需要保留一个“历史遗留”分组，不能把未完成记录隐藏到无法处理。

### 10.3 上传状态

| 状态 | 用户文案 | 操作 |
| --- | --- | --- |
| pending | 待上传 | 等待或查看详情 |
| uploading | 上传中 | 查看实时进度 |
| uploaded | 已上传 | 复制查询码、查询日志 |
| uncertain | 待核对 | 平台核对后重试或确认 |
| dead | 上传失败 | 查看失败原因 |

### 10.4 实时上传信息

每条记录展示：

- 串口号。
- 项目、版本、测试任务。
- 文件名、文件大小。
- 当前状态。
- 已上传字节/总字节。
- 百分比。
- 实时速度。
- 开始时间、完成时间和耗时。
- 重试次数、下次重试时间。
- 最后错误。
- 查询码。

> 当前上传实现没有向前端提供字节级进度和速度事件。该能力需要调整 Go 上传客户端，不能只靠前端模拟。

### 10.5 查询码

查询码用于用户在云端查询日志或分析结果。

显示规则：

| 队列状态 | 查询码显示 |
| --- | --- |
| 待上传 | 尚未生成 |
| 上传中 | 等待平台返回 |
| 已上传 | 显示查询码和复制按钮 |
| 待核对 | 待平台核对 |
| 上传失败 | 未生成 |

推荐后端上传成功响应新增：

```json
{
  "code": 0,
  "data": {
    "upload_id": "...",
    "task_id": "...",
    "query_code": "LM-20260727-A8K4P2",
    "file_count": 1
  }
}
```

当前后端契约只有 `upload_id` 和 `task_id`。在新增字段前，可以临时把 `task_id` 作为查询码展示，但产品文案和接口契约必须明确，不能让前端自行生成不可查询的号码。

推荐查询码按“一次串口采集会话”生成，使同一会话的多个分段文件共用一个查询码：

```text
一次采集会话
  COM24-...-001.log
  COM24-...-002.log
  COM24-...-003.log
          -> LM-20260727-A8K4P2
```

要实现会话级查询码，平台需要支持客户端 `session_id`，或提供将多个上传批次关联到同一查询码的接口。

## 11. 存储占用

### 11.1 全局存储

- 显示日志根目录总占用。
- 显示最大允许占用。
- 显示百分比和剩余空间。
- 正常、预警、禁止新增采集使用不同状态，不只依赖颜色表达。

### 11.2 每端口存储

左侧通道显示简要占用，选中端口后在右侧下方显示：

- 当前端口总占用。
- 当前采集会话占用。
- 待上传文件占用。
- 已上传保留文件占用。
- 文件数量。
- 最早和最新文件时间。
- 打开目录按钮。

磁盘保护要求：

- 不得自动删除未上传文件。
- 不得自动删除 `uncertain` 文件。
- 达到禁止阈值时停止新增正式日志写入，并给出明确告警。

## 12. 配置管理与导入预览

### 12.1 配置内容

配置文件至少包含：

- 配置版本号。
- 项目稳定 ID 和名称。
- 项目可选版本。
- 测试任务稳定 ID、名称和类型。
- 关键字方案。
- 关键字规则。

建议结构示例：

```yaml
schema_version: 1
projects:
  - id: project-a
    name: Project A
    versions:
      - V1.0.0
      - V1.1.0
    tasks:
      - id: normal-aging
        name: 普通挂测
        type: normal
        keyword_profiles:
          - id: default-errors
            name: 默认异常关键字
            rules:
              - id: reboot
                name: 设备重启
                match: "reboot"
                mode: contains
                case_sensitive: false
              - id: timeout
                name: 通信超时
                match: "timeout|timed out"
                mode: regex
                case_sensitive: false
```

最终字段以用户提供的正式配置文件为准。本示例只用于确定前端层级和稳定 ID 要求。

### 12.2 导入流程

```text
选择文件
  -> 解析和校验
  -> 展示差异预览
  -> 用户确认
  -> 应用配置
  -> 显示结果和错误
```

### 12.3 差异预览

预览必须分组显示：

- 新增项目、任务、关键字。
- 修改项目、任务、关键字。
- 删除项目、任务、关键字。
- 无变化项数量。
- 校验错误和警告。

修改项需要显示旧值和新值。删除项必须醒目提示：

- 哪些现有串口正在引用该项目或任务。
- 哪些关键字统计将无法继续使用。
- 历史日志保留原始名称和 ID，不得被新配置反向改写。

存在解析错误或稳定 ID 冲突时禁止应用。导入不能静默覆盖当前配置。

## 13. 全局设置

建议包含：

### 日志

- 默认日志保存位置。
- 打开默认日志目录。
- 默认自动保存开关。
- 默认文件分段时间。
- 默认文件分段大小。
- 日志窗口最大行数。
- 默认自动换行。
- 长时间无日志默认告警阈值。

### 上传

- 后端地址，只允许有权限的用户修改。
- 上传超时。
- 上传并发数。
- 上传间隔。
- GZIP 开关。
- 上传鉴权状态，但不明文显示 Token。

### 存储

- 最大本地存储阈值。
- 存储预警阈值。
- 已上传文件保留时间。
- 打开数据目录。

### 程序信息

- 程序版本。
- 构建版本。
- 更新日期。
- 检查更新入口。
- 交流群二维码、群号或加入链接。

交流群信息由用户后续提供，设计稿需要预留固定区域和缺省状态。

## 14. 底部状态栏

底部状态栏分为三部分：

- 左侧：当前选中通道状态、最后日志时间、未保存配置提示。
- 中央：实时时间，格式 `[yyyy-MM-dd HH:mm:ss.SSS]`。
- 右侧：本地服务状态、磁盘预警、待上传数量、待人工核对数量。

中央时间每 100ms 或 250ms 刷新即可，不需要为显示毫秒进行高频逐毫秒渲染。

## 15. 退出保护

关闭程序时需要分别检查：

- 是否有正在采集的串口。
- 是否有未保存通道配置。
- 是否有正在上传的文件。
- 是否有 `uncertain` 批次。

提示需要明确说明关闭的影响。正常退出必须释放全部串口并封口已生成的内部日志文件。

## 16. 前后端接口调整清单

以下能力不能仅通过调整 Vue 页面完成：

| 能力 | 所需调整 |
| --- | --- |
| 首次打开失败不重连 | 采集状态机区分首次打开错误和运行中断线 |
| 最后日志时间 | `DeviceStateDTO` 增加 `lastLogAt` |
| 长时间无日志告警 | Go 层维护阈值、最后接收时间和告警状态 |
| 正式日志保存开关 | 分离实时显示、正式落盘和上传策略 |
| 每通道云端上传开关 | 分段入队时读取通道上传策略 |
| 另存完整采集会话 | Wails 提供安全的本地文件对话框和复制接口 |
| 历史文件 | 提供文件索引、筛选、预览和状态接口 |
| 关键字命中详情 | 持久化规则 ID、命中时间、逻辑行号和文件定位信息 |
| 实时上传进度 | 上传客户端上报已发送字节、总字节和速度 |
| 查询码 | 后端返回 `query_code` 或确认使用 `task_id` |
| 会话级查询码 | 客户端和后端共同支持稳定 `session_id` |
| 每端口存储占用 | 后端按设备和上传状态统计文件占用 |
| 配置导入预览 | 配置解析、校验、稳定 ID 差异计算和原子应用 |
| 打开日志目录 | Wails 调用 Windows 文件管理器并处理目录错误 |

## 17. 验收要点

### 串口与采集

- 打不开的串口只尝试一次并给出明确警告。
- 单路打开失败不影响其他串口。
- 每路显示真实最后日志时间。
- 达到无日志阈值后告警，恢复数据后自动解除。
- 波特率支持五个预设值和手动输入。

### 日志窗口

- 时间戳严格符合 `[yyyy-MM-dd HH:mm:ss.SSS]`。
- 不显示固定 INFO 等级列。
- 搜索按钮、上下定位、`当前/总数` 和继续滚动完整可用。
- 清屏不删除文件。
- 自动换行和复制整行可用。
- 另存日志不修改上传文件和上传队列。
- 导出打印窗口只导出清屏后窗口内日志。

### 配置和关键字

- 项目、版本、任务、关键字方案联动正确。
- 未保存配置不能开启正式保存和云端上传。
- 每个关键字显示次数、时间和行号。
- 点击命中记录可以定位或明确提示需要查看历史。
- 导入配置前正确显示新增、修改和删除项。

### 上传

- 队列按已开启云端上传的串口展示。
- 关闭上传后不再为新文件创建上传任务。
- 已存在的未完成任务不会因关闭开关而消失。
- 上传进度来自真实发送字节，不使用前端假进度。
- 上传成功后可复制查询码并执行查询。
- 响应未知继续进入 `uncertain`，不得自动盲目重传。

### 存储和设置

- 全局和每端口存储占用数据一致。
- 日志目录按钮打开正确目录。
- 设置页显示程序版本、更新日期和交流群预留区。
- 底部中央时间格式与日志时间戳一致。

## 18. 待确认事项

以下事项需要在高保真设计或接口开发前确认：

1. 已连接设备被拔出后，是保持开关开启并等待重插，还是直接关闭开关。
2. 未完成首次日志配置时，是否允许写入临时诊断日志；本文默认只显示实时日志，不写正式业务日志。
3. “另存日志”的默认范围是当前窗口，还是本次采集全部日志。
4. 关闭云端上传后重新开启，是否生成新的采集会话和查询码。
5. 查询码最终使用现有 `task_id`，还是由平台新增独立 `query_code`。
6. 查询码按上传批次生成，还是按一次串口采集会话生成；本文推荐会话级查询码。
7. 关键字匹配是否需要前后文，以及默认保存多少行前后文。
8. 用户提供的正式项目/任务/关键字配置文件格式和版本迁移策略。

## 19. 当前范围外能力

以下能力不应在本轮前端设计中默认承诺：

- RTS/CTS 和 XON/XOFF 流控。
- 云端 exactly-once 上传。
- 后台托盘常驻采集。
- 远程控制串口。
- 在线自动升级。
- AI 分析结果展示。
- 多用户权限和操作审批。

如需加入，应单独确认后端接口、运行方式和验收标准。
