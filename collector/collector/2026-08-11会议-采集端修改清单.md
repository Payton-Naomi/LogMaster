## 一、会议反馈 → 采集端修改项对照总表

| # | 会议反馈（原文要点） | 采集端现状 | 修改结论 |
|---|---------------------|-----------|---------|
| A | 串口通道最多 8 个不够，加 USB hub 十几台机器同时抓 | `internal/collector/types.go` `MaxSupportedDevices = 8`，manager 和 desktop 均硬限制 | **放开限制**，跟随 Windows 实际串口数 |
| B | "上传云端"按钮放到上面做成开关，不开时不展示下面项目/版本等参数 | `ChannelInspector.vue` 上传字段常显，开关在最底部 | **UI 重构**：开关置顶 + 未开启时折叠上传参数区 |
| C | 后端地址写死不可改，云迁移不该出新版本，要能写进配置文件 | `SettingsView.vue` 后端地址 Input `disabled`；`config.yaml`/`LOGMASTER_CONFIG` 已能覆盖但无 UI 入口 | **设置页解锁编辑** + 文档说明 config.yaml 覆盖方式 |
| D | 本地关键字只能勾选，要能自己增加关键字方案；云端新增关键字本地要能同步（token+密钥接口，不做登录） | catalog 内置只读（`catalog.go` `SelectCatalogFile` 直接报错）；无云端同步接口 | **两步**：① 支持本地自定义关键字方案（与内置合并持久化）② 用现有 Bearer token 调服务端 catalog 同步接口 |
| E | 换电脑后上传人/测试备注没保留（自认 bug） | `configForPortLocked` 新串口无历史记录，`applyLogConfigDefaultsLocked` 清空字段 | **新通道继承最近一次配置的上传人/备注**（全局历史 + USB serial 匹配） |
| F | 解压失败要加弹框（vlog 密码错误提示"解压失败"但实际 OK） | 采集端无 vlog 解密逻辑（服务端做）；失败只有笼统提示 | 服务端上传/解析状态透出 → **采集端对"解析失败/解压失败"状态弹框提示** |
| G | 本地的、线上的都要加日志模块，上传失败只有"上传失败"弹窗没法排查 | `slog.Default()` 写 stderr，桌面端不可见，无日志文件 | **新增滚动日志文件**（上传失败详情/HTTP 状态/重试轨迹落盘）+ 设置页"打开日志目录" |
| H | 上传码前面加项目名称关联，像票据号 | 查询码为服务端 8 位码，采集端原样展示 | 展示为"项目名-查询码"；码格式带项目前缀需**服务端配合** |
| I | 上传重试：挂一晚上两次没传上去，第二天要能手动重传 | 自动重试指数退避（1s→30s 封顶，无限次）；历史文件手动重传已支持（`RetryUncertain`） | 保留现状 + 失败批次 UI 醒目标记、一键重传入口完善 |
| J | 项目名称不存在时能不能自动创建 | `device_settings.go:99` 失败只提示"上传失败，请重试"，不透明 | **透出服务端错误信息**（如"项目不存在，请联系管理员创建"）；自动创建按会议结论不做，走管理员核对 |
| K | 上传人重名，加邮箱后缀 | 只传 `uploader_name` | 上传人增加邮箱字段一并提交（服务端配合匹配） |
| L | 分片上传 1800s / 128MB，串口断开超时告警 | 已是默认值（`app_settings.go` normalize 1800s / 128MB），设置页可调 | 无需改动 |
| M | 关闭串口时可选择继续/停止上传 | 已实现（`DisconnectDeviceWithUploadPolicy`） | 无需改动 |
| N | 串口参数（波特率/数据位等）配置文件里加 | 波特率/数据位/停止位/校验位 UI 可改；`config.yaml` 支持 `serial.ports` | 基本满足，可补：通道配置导出/导入到 config.yaml |
| O | 测试场景关键字"多条按行输入 + 加号按钮" | 属于 Web 端测试场景管理页 | 不在采集端，转 Web 端 |
| P | AI 解析 | 接口预留，暂不接大模型 | 无需改动 |

## 二、分优先级实施计划

### P0 —— 本次必须先改（会议点名、影响挂测）

1. **A 放开串口数量限制**
   - `internal/collector/types.go`：`MaxSupportedDevices` 8 → 64（或按需）
   - `internal/collector/manager.go`：上限校验同步
   - `desktop/service.go`：`collector.Config{MaxDevices: 8}` 改为读配置；`loadSettings` 的 "exceed eight devices" 错误同步改
   - 注意：`EventCapacity`、`configs` map、UI 通道列表均为动态，无其他硬编码

2. **B 上传云端开关置顶 + 折叠上传参数**
   - `desktop/frontend/src/components/ChannelInspector.vue`：
     - 把"上传云端"开关移到"通道配置"表单顶部
     - 项目名称/版本号/测试任务/上传人/测试备注/关键字方案/选择关键字整体包进 `v-if="draft.uploadEnabled"`（`<Transition>` 折叠展开）
     - 未开启时保存不再校验项目/版本/上传人（`validateUploadPrerequisites` 已按 UploadEnabled 分支，无需改 Go）

3. **G 本地日志模块**
   - 新增 `desktop/logging.go`：`%APPDATA%\LogMaster\logs\collector.log` 滚动日志（按天/10MB 切分，保留 7 天）
   - `service.go` `newServiceAtConfig` 里替换 `slog.Default()`：`backend.NewWorker(..., logger)` 传入文件 logger
   - 上传失败/成功、`CreateUploadSession` 失败、重试调度均记录结构化日志
   - `SettingsView.vue` 云端上传卡片加"打开日志目录"按钮（`runtime.BrowserOpenURL` 或新增 `OpenLogDirectory` 绑定）

4. **J 服务端错误信息透出**
   - `desktop/device_settings.go:97-99`：`CreateUploadSession` 返回的错误信息（HTTP/业务 code/message）放入 `DeviceConfigSaveResult.Message` 展示，不再统一"上传失败，请重试"
   - `internal/backend/client.go`：`CreateUploadSession` 的 `fmt.Errorf` 已含服务端 message，确认错误链能到 UI

### P1 —— 尽快跟进（体验与排查）

5. **C 后端地址可配置**
   - `SettingsView.vue`：后端地址 Input 去掉 `disabled`（保存仍走 `SaveAppSettings`，已有持久化）
   - 上传间隔/并发数保持只读或一并放开
   - 文档 `docs/user-guide.md` 补充：`config.yaml`（exe 同级或 `LOGMASTER_CONFIG`）可覆盖 `backend.base_url`，云迁移不用发版

6. **E 上传人/备注历史（已反向决策：不保留历史）**
   - 最终决定与会议当场讨论相反：通道**不保留**历史配置（见实施进度 K 项），因此此条取消。

7. **H 查询码展示带项目关联**
   - 前端查询码展示处（`UploadQueueView`/通道检查器）格式化为"项目名-查询码"
   - 服务端生成码加项目前缀（另立项，跟 Web 端对契约）

8. **I 失败批次一键重传完善**
   - `UploadQueueView.vue`：Dead/Uncertain 批次加醒目状态徽标 + "重新上传"按钮（`RetryUncertain` 已存在，确认前端绑定）

### P2 —— 中期（依赖服务端接口）

9. **D 关键字方案：本地自定义 + 云端同步**
   - 本地自定义：`catalog.go` 恢复导入能力并改为"合并"语义——用户文件 `project-catalog.yaml` 与内置 catalog 合并（用户项优先/追加），`SelectCatalogFile`/`ApplyCatalogImport` 解除只读限制
   - 云端同步：`internal/backend/client.go` 新增 `FetchCatalog`（带 `Authorization: Bearer <token>`，无登录），服务端需提供 `GET /collector-catalog`（或等价）接口；启动时/手动"同步项目配置"按钮拉取并合并
   - UI：`CatalogView.vue` 增加"同步云端配置"按钮与"导入本地配置文件"入口

10. **K 上传人邮箱**
    - `DeviceConfigDTO` 增加 `UploaderEmail`；`uploadSessionRequest`/`multipartBody` 字段一并上传
    - 与 Web 端约定字段名（如 `uploader_email`），服务端按邮箱唯一匹配，中文名仅展示

11. **F 解压失败弹框**
    - 需要服务端在上传会话/批次状态中回传解析结果（如 `parse_status: decompress_failed`）
    - 采集端轮询会话状态或接收状态字段，命中失败时 `Modal` 弹框展示文件名与失败原因

### 不在此端改动
- O 测试场景关键字"加号逐条添加" → Web 端测试场景页
- N 串口参数配置文件：现 UI + config.yaml 已覆盖，如需"通道配置导出/导入"再立项
